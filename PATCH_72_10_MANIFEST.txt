PATCH 72.10 MANIFEST - Trust Upload Auto-Normalizer

Patch ID: 72.10
Patch name: Trust Upload Auto-Normalizer
Owner/User: Johnny Cortes Vega
Project: ALETHEIA v1.0 - Governance Mirror

Purpose:
- Let Evidence Lab accept public trust uploads without requiring the user to manually convert them into ALETHEIA-ready CSV format.
- Auto-map common OWID/self-reported trust columns such as Entity, Code, Year, and Trust in others.
- Normalize 0-100 trust percentages to ALETHEIA's 0-1 `wvs_generalized_trust` scale.
- Report the trust transform in upload diagnostics.

Files changed:
- core/empirical.py
- core_empirical.py
- tests/test_patch_72_10_trust_upload_auto_normalizer.py
- PATCH_72_10_MANIFEST.txt
- PATCH_72_10_RECOVERY_NOTE.md
- PATCH_STATUS.md
- docs/progress_database.md

Behavioral changes:
- `prepare_empirical_frame(...)` now recognizes trust columns including:
  - `Trust in others`
  - `trust_in_others`
  - `trust_others`
  - `trust_in_other_people`
  - existing generalized-trust aliases
- Trust values on a 0-100 percentage scale are normalized to 0-1.
- Already-normalized 0-1 trust values are preserved.
- `_aletheia_trust_upload_note` records the detected source column and scale handling.
- `public_upload_diagnostics(...)` exposes the transform note.

Non-goals:
- No scoring formula change.
- No verdict-routing change.
- No 9k allocation formula change.
- No World Lens logic change.
- No receipt schema change.
- No authority, public ledger, Global ID sync, central storage, or enforcement behavior.
