PATCH 72.14 MANIFEST - World Lens Value Guard Fallback

Patch ID: 72.14
Patch name: World Lens Value Guard Fallback
Owner/User: Johnny Cortes Vega
Project: ALETHEIA v1.0 - Governance Mirror

Purpose:
- Prevent World Lens from crashing with `NameError: selected_year_value_guard` when an older deployment or partial patch has app.py calling the guard before the core helper is available.
- Keep the selected-year value guard diagnostic visible using a local fallback.
- Preserve the full 9k selected-year view and selected-year coverage metrics.

Files changed:
- app.py
- tests/test_patch_72_14_world_lens_value_guard_fallback.py
- PATCH_72_14_MANIFEST.txt
- PATCH_72_14_RECOVERY_NOTE.md
- PATCH_STATUS.md
- docs/progress_database.md

Behavioral changes:
- World Lens now resolves `selected_year_value_guard` through a safe callable lookup.
- If the imported helper is unavailable, a local diagnostic-only fallback computes:
  - selected year
  - total seats
  - seat total OK
  - stale-year-row check
  - focus row availability
  - focus trust/verdict labels where available
- The fallback does not create authority or change scoring.

Non-goals:
- No scoring formula change.
- No verdict-routing change.
- No 9k allocation formula change.
- No Evidence Lab data model change.
- No receipt schema change.
- No public ledger, Global ID sync, central storage, or enforcement behavior.
