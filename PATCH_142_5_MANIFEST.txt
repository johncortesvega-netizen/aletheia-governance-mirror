PATCH 142.5 — Receipt Reader Batch ZIP Receipt Selection Fix

Status: READY FOR LOCAL REVIEW

Purpose
- Fix Receipt Reader batch ZIP handling so batch index files are used only for indexing/summary context and are not inspected as if they were receipts.
- Ensure the first inspectable receipt in a batch ZIP is an actual receipt file, preferring receipt_01.json over receipt_01.txt when both exist.

- Batch ZIP parsing filters out batch_index.txt and batch_index.json from inspectable receipt views.
- Receipt ZIP parsing deduplicates receipt_XX.json / receipt_XX.txt pairs by receipt index and prefers JSON.
- Batch summary now reports actual receipt count, native-state distribution, risk distribution, and module/source distribution from actual receipt files.
- The inspect panel opens the first real receipt file rather than batch_index.txt.
