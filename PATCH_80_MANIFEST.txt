- Document direct APK sharing cautions without changing the Streamlit app or governance mirror engine.

Explicit non-goals:
- No keystore or password is included.
- No signed APK is committed.
- No native rewrite.
- No offline mobile capability claim.
- No new permissions beyond the Patch 79 internet-only wrapper posture.
- No scoring, verdict, receipt, Evidence Lab, World Lens, or authority-boundary changes.

Compatibility note:
- This patched-items zip includes the Patch 79 Android WebView wrapper files as well as Patch 80 signing additions, so it can be applied to a local tree that has not separately merged Patch 79 yet.
- If Patch 79 is already applied, these wrapper files should overwrite with the same intended content plus Patch 80 release-signing support.
