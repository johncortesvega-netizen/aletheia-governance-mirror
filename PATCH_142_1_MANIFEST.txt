Behavior changes:
- Receipt Reader now prefers the MACHINE-READABLE RECEIPT JSON block when present.
- Receipt Reader falls back to text parsing only when machine-readable JSON is unavailable.
- Text fallback accepts `Risk:` as the risk field and `Trust index:` as trust.
- Repair questions are extracted from JSON `repair_questions` or the `SILENT OPERATOR REPAIR QUESTIONS` section only.
- Threshold component readings are not treated as repair questions.
- Values render as a compact vertical list so uploaded receipt values align more clearly.

Shared utility note:
- Receipt Reader remains a single support utility for uploaded ALETHEIA receipt files from any module.
- It reads common receipt fields such as module, verdict, metrics, and repair questions without changing the source receipt.
