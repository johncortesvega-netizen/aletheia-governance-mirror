PATCH 72.2 MANIFEST - Mirror Check Input Change Reset

Patch ID: 72.2
Patch name: Mirror Check Input Change Reset
Owner/User: Johnny Cortes Vega
Project: ALETHEIA v1.0 - Governance Mirror

Purpose:
- Prevent a previous Mirror Check assessment/receipt from staying active after the user edits or replaces the input text.
- Require an explicit new `Review idea` click before the app shows a new active reading and receipt for changed input.
- Preserve previous readings as history without treating them as the current draft.

Files changed:
- app.py
- tests/test_patch_72_2_mirror_check_input_change_reset.py
- PATCH_72_2_MANIFEST.txt
- PATCH_72_2_RECOVERY_NOTE.md
- PATCH_STATUS.md
- docs/progress_database.md

Behavioral changes:
- Added a stable input signature helper for Mirror Check text.
- Stored the active input signature only after an explicit Review idea run.
- The latest-reading and receipt flow now renders only when the current text matches the last explicitly reviewed input.
- When input changes, the app shows a notice that the previous assessment is closed for the current draft and asks the user to click Review idea again.
