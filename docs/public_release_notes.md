# ALETHEIA v0.1 — Public Release Notes

## Release posture

ALETHEIA v0.1 is a public-safe governance mirror prototype. Its purpose is to make governance-risk review more structured, transparent, and repair-oriented.

It does not command, enforce, vote, govern, remove leaders, validate spiritual authority, or replace human judgment.

## What v0.1 includes

- Baseline v0.1 and Safe Language Layer.
- Eternal Baseline as a versioned ethical reference layer.
- Boundary Cases Matrix.
- Failure Classification.
- Consent-Audit Engine.
- Mechanism-vs-Claim Scanner.
- Self-Audit Mode.
- Evidence Lab and Extraordinary Claim Protocol.
- Local Witness Receipt v2.
- World Lens Simulation.
- Protocol Guide consolidation.
- Progress Database and local patch workflow.
- Public limitations and ethics pages.

## Public message

> Upload a governance document or scenario. ALETHEIA helps you see capture risk, missing safeguards, evidence gaps, consent pressure, and repair needs. Final judgment remains human.

## Not included in v0.1

v0.1 does not include real Global ID sync, real 9k selection, real World Leader logic, automatic resets, public ledger authority, central citizen storage, neural data, memory extraction, or automated enforcement.

## Release boundary

This is a research and review tool. Outputs are diagnostic and correctable. They are not legal, political, medical, religious, moral, or predictive verdicts.
