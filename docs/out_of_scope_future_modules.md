# Out-of-Scope Future Modules

Status: Boundary document
Purpose: Prevent future-planning language from being mistaken for current capability

## Not Included in ALETHEIA v1.0

ALETHEIA v1.0 does not include:

- real Global ID sync
- real 9k moderator selection
- World Leader logic
- automatic resets
- public ledger authority
- central citizen database
- neural data
- memory extraction
- spiritual validation
- legal authority
- political authority
- automated enforcement

## Future-Only Discussion Topics

The following may appear in concept notes, but must not be represented as implemented features:

- population-scale identity systems
- live public voting systems
- neural validation systems
- cross-platform governance enforcement
- sovereign delegation systems
- automatic deactivation of leaders
- divine, prophetic, alien, neural, or metaphysical verification

## Safe Public Rule

If a module is not implemented, tested, and bounded by human review, it must be described as a future concept only.

ALETHEIA reflects. Humans review. Power stays accountable.
