# AI Integrity Preview — Screenshots Guidance

Use screenshots to explain ALETHEIA quickly without turning outputs into authority claims.

## Recommended screenshots

1. AI Integrity Mirror empty state, showing the static-review boundary.
2. Single-artifact result with grouped categories, highest pressure signals, repair questions, and collapsed evidence snippets.
3. Batch Review using `examples/ai_integrity/batch_demo_v1.txt`.
4. Code Integrity Static Scan panel using a safe synthetic demo snippet.
5. Privacy Boundary Audit Panel showing local-only statement and hosting caveat language.
6. Comparison View with multiple pasted artifacts.
7. Report Builder preview and local text download.

## Caption style

Use captions such as:

- "Static artifact-level review for human inspection."
- "Evidence snippets are redacted and local to the running session."
- "This is not model certification, vendor ranking, security certification, or a privacy guarantee."
- "ALETHEIA reflects signals; people decide what review or repair is needed."

Avoid captions that imply final truth, deployment approval, automated enforcement, legal advice, medical advice, political authority, religious authority, privacy proof, security proof, or model-wide safety certification.
