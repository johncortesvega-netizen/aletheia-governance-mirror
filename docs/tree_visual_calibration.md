# Patch 70 — Tree Visual Calibration

Patch 70 clarifies the tree visual used in Mirror Check and Stress Test.

The tree is a **state explainer**, not a second authority layer and not a replacement for the local witness receipt. The receipt remains the canonical record for protocol-adjusted integrity, hashes, authority boundary, and repair questions.

## State taxonomy in the tree

### SANCTUARY
Low capture signal. The pattern appears relatively reviewable and repairable.

This does **not** mean approval, certification, or permission. Human review is still required.

### THRESHOLD
Boundary condition. The pattern needs clearer safeguards before trust can increase.

Typical missing pieces include appeal, exit, evidence, correction, independent review, time limits, or basic-rights protection.

### ASYLUM
Protective review signal. The pattern may contain coercion, capture, permanent power, basic-rights pressure, or non-appealable authority.

This is not enforcement and not an automated decision.

### QUESTION_PROMPT
Review Tool Mode. The input is an audit or repair question, not a scored governance scenario.

Question prompts are preserved as review tools. They should not render as Sanctuary, Threshold, or Asylum.

## Mirror Check tree

Mirror Check reads documents, proposals, and audit questions as a governance mirror.

The Mirror Check tree uses:

- Root: Human review
- Trunk: Evidence + accountability
- Branches: Safeguards, appeal, transparency, repair, basic rights, non-coercion

## Stress Test tree

Stress Test reads concrete scenarios under pressure.

The Stress Test tree uses:

- Root: Human dignity
- Trunk: Power under stress
- Branches: consent, exit, appeal, time limits, independent review, evidence clarity, basic rights

## Score wording

Patch 70 separates two concepts:

- **Visual tree score**: display signal used to render the tree state.
- **Protocol-adjusted integrity**: numeric reading stored in the receipt.

A visual tree score may be capped by the final risk state so a high raw integrity value does not produce a green tree after a guardrail escalates the result to THRESHOLD or ASYLUM.

## Safe-language boundary

The tree must not use words like approved, rejected, dangerous person, AI decision, automatic reset, or enforcement.

Use signal, review required, needs safeguards, repair path, human review, and mirror only.
