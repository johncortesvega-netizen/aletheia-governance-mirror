# ALETHEIA v0.1 — GitHub Cleanup Package

Status: Patch 55
Purpose: prepare the repository for public review without expanding ALETHEIA authority.

## Public repository goal

The repository should let a new reviewer understand ALETHEIA in a few minutes:

- what the app is
- what the app is not
- how to run it locally
- how to run the current safe checks
- where the core docs, prompts, examples, and tests live
- which v0.1 boundaries are intentionally out of scope

## Public interpretation

ALETHEIA v0.1 is a governance mirror for human review. It can surface capture risk, consent pressure, evidence gaps, safeguard gaps, and repair gaps. It does not command, enforce, vote, govern, validate spiritual authority, remove leaders, replace legal judgment, or replace human judgment.

## GitHub-ready package checklist

- README explains the project in public-safe language.
- `docs/limitations.md` and `docs/ethics.md` are linked before strong claims.
- `docs/repository_map.md` explains where important files live.
- `docs/contributing.md` explains safe contributions and test commands.
- `examples/` contains demonstration artifacts only.
- `PATCH_STATUS.md` and `docs/progress_database.md` preserve local continuity.
- Historical archive material is treated as development context, not founder validation.

## Do not publish as

ALETHEIA must not be framed as:

- a government
- a legal authority
- a religious authority
- a medical authority
- a sovereign system
- a leader-selection system
- a Global ID system
- a neural validation system
- an automated enforcement system
- proof that any founder, model, doctrine, or claim is correct

## Public release line

ALETHEIA reflects. Humans review. Power stays accountable.
