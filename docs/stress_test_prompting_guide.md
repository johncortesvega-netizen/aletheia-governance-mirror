# Stress Test Prompting Guide

ALETHEIA Stress Test works best when the input is written as a governance scenario, not as a personal accusation.

## Good scenario ingredients

Include as many of these as you can:

- who gains power
- how power is obtained
- what can go wrong
- which safeguards exist
- which safeguards are missing
- whether affected people can appeal
- whether affected people can exit
- whether the decision can be corrected
- whether the power is time-limited
- whether basic rights remain protected

## Weak vs better inputs

Weak:

```text
Is this bad?
```

Better:

```text
A temporary crisis leader gains emergency authority after a disaster, but no term limit, appeal path, or independent review is defined.
```

Weak:

```text
John is evil.
```

Better:

```text
A named leader gains centralized authority after a crisis. The system has weak review, unclear limits, and no visible exit path.
```

## Safe testing rules

- Use fictional names or role labels when testing.
- ALETHEIA reviews patterns, not personal worth.
- The Invisibility Filter can reduce actor, name, and title bias.
- The governance pattern should remain visible after filtering.
- Stress Test outputs are mirror signals for human review, not authority decisions.

## Batch stress testing

Batch stress testing should use one scenario per line or a numbered list. Keep each scenario concrete enough that the scanner can see power, safeguards, appeal, evidence, or failure modes.

The batch tester remains local-only. It produces local witness receipts and does not publish, sync, or create authority.
