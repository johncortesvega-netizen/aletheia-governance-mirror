# ALETHEIA v0.1 — Safe Language Map

Purpose: preserve visionary meaning while preventing authority leakage, enforcement language, spiritual validation claims, or founder-capture framing.

| Visionary or high-authority term | App-safe term |
|---|---|
| Noodrem | Critical Review Trigger |
| Automatische reset | Human review required |
| Automatische deactivering | Governance failure flag |
| Divine Exception | Extraordinary Claim Protocol |
| Jezus-doctrine | Public Ethics Baseline |
| Will-takeover | Coercive agency override |
| Team Human | Human dignity and basic rights filter |
| Lord's Break | Unresolved extraordinary scenario |
| World Leader reset | Simulated governance failure signal |
| 75% trigger | Simulated threshold signal |
| AI blocks implementation | Critical risk detected |
| AI decides | ALETHEIA reflects for human review |
| Verified divine authority | Unverified extraordinary claim |
| System reset required | Critical human review required |
| Remove the leader | Review governance failure risk |

## Output rule

Use diagnostic language:

- Potential risk detected.
- Human review required.
- Safeguard missing.
- Evidence gap found.
- This claim is unverified.
- Critical review trigger.
- Governance failure flag.
- Simulated threshold signal.

Avoid command language:

- The AI has decided.
- This leader must be removed.
- This claim is divinely verified.
- The guardrails no longer apply.
- Human review is unnecessary.
