# Report Export Polish

Status: v0.2 candidate / v1.0 documentation boundary
Purpose: Define how exported reports should remain reviewable, local, and non-authoritative

## Export Principle

Reports should be easy to save and share, but the export must not turn a mirror report into an authority document.

Every exported report should include:

- document title or user label
- timestamp
- ALETHEIA version
- rubric/prompt version where available
- active modules
- report sections
- evidence gaps
- recommended safeguards
- human review disclaimer
- local receipt metadata where available

## Required Disclaimer

This report is a governance mirror for human review. It is not authoritative, legal advice, policy command, enforcement, spiritual validation, or a replacement for human judgment.

## Export Formats

Recommended future export formats:

- Markdown
- plain text
- local receipt JSON or text
- PDF only if it preserves disclaimers and metadata

## Safety Boundary

Export polish must not add public ledger authority, central storage, Global ID sync, legal authority, spiritual validation, or automated enforcement.
