# ALETHEIA v0.2 Roadmap

Status: Future planning after ALETHEIA v1.0 public MVP
Authority level: Planning only

## Purpose

The v0.2 roadmap protects the v1.0 boundary by separating future ideas from the finished public MVP.

ALETHEIA v1.0 is a governance mirror for human review. It does not command, enforce, vote, govern, remove leaders, validate spiritual authority, replace legal review, or replace human judgment.

v0.2 should expand review usefulness without changing that boundary.

## Candidate v0.2 Features

1. Side-by-side document comparison
2. Cleaner Markdown report export
3. Reviewer notes and human comments
4. Manual evidence attachment
5. Rubric weighting controls
6. Confidence and uncertainty notes
7. Source-quality labels
8. Multi-model review workflow
9. Improved demo input runner
10. Better release packaging for public demos

## v0.2 Safety Rule

Every future feature must pass the same baseline:

- human dignity
- basic rights
- free agency
- transparency
- appealability
- accountability
- evidence
- repair
- non-coercion
- human review

## Non-Expansion Boundary

v0.2 planning must not smuggle in:

- real Global ID sync
- real 9k selection
- World Leader logic
- automatic reset
- public ledger authority
- neural data
- memory extraction
- religious validation
- legal authority
- automated enforcement

## Release Rule

A feature belongs in v0.2 only if it helps humans review better while keeping ALETHEIA a mirror, not a throne.
