# Contributing to ALETHEIA v0.1

Thank you for reviewing or improving ALETHEIA. Contributions should preserve the core boundary: ALETHEIA is a mirror for human review, not an authority system.

## Safe contribution principles

Contributions should strengthen:

- transparency
- appealability
- accountability
- evidence handling
- repair mechanisms
- human review
- non-coercion
- basic-rights awareness
- founder-capture resistance

Contributions should not introduce:

- automated enforcement
- leader removal language
- divine verification language
- legal authority claims
- Global ID sync
- real 9k selection
- neural data processing
- public ledger authority
- central citizen databases

## Local checks

Run the current safe check workflow from the project root:

```bat
tools\run_checks.bat
```

Run a specific patch check:

```bat
tools\run_patch_checks.bat 55
```

## Patch style

Preferred patch style:

1. small scope
2. patched-items-only output
3. recovery note
4. manifest
5. focused test
6. no authority expansion

## Git workflow

The patched-items-only zip workflow remains valid. Contributors who use Git may follow `docs/git_diff_workflow.md`.
