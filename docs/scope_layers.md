# ALETHEIA Scope Layers

ALETHEIA uses a layered scope model so public readers can separate the working prototype from the broader theory.

## 1. Current operational layer

ALETHEIA is currently a corruption-pattern and governance-risk detection framework. It acts as a mirror for human review by surfacing:

- evidence gaps
- consent pressure
- capture risk
- power concentration
- missing safeguards
- appealability and repair gaps
- authority-overreach signals

This layer is what the current Streamlit app is meant to do. It does not decide what should happen next.

## 2. Research layer

The research layer contains hypotheses, scenario tests, benchmark cases, empirical mappings, validation work, and documentation that may make the mirror more precise over time.

Research outputs remain reviewable and correctable. They are not proof of legal, political, moral, religious, medical, predictive, or final truth.

## 3. Vision layer

ALETHEIA's long-term theory explores the logic of an incorruptible governance architecture. The theory asks what governance would look like if anti-corruption principles were followed consistently:

- transparency
- consent
- accountability
- proportionality
- human dignity
- appealability
- repair
- limits on concentrated power

This vision layer is a theoretical horizon, not a claim that such a system is implemented, politically authorized, institutionally available, or technically complete.

## 4. Out-of-scope layer

ALETHEIA does not:

- govern
- enforce
- command
- vote
- remove leaders
- allocate authority
- select representatives
- create a real 9k body
- issue political mandates
- validate spiritual, legal, political, medical, or institutional authority
- replace human judgment

## Operating summary

The incorruptible system is the theory horizon. The current tool is the mirror.

ALETHEIA tests governance language and power structures against anti-corruption principles so humans can review evidence, consent, accountability, dignity, proportionality, appealability, and non-domination more clearly.
